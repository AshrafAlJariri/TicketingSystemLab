# TicketingSystemLab

## Description

I created this lab to practice how IT help desk teams use a ticketing system to document, manage, escalate, resolve, and close support tickets. I used Spiceworks to simulate common help desk workflows and improve my ticket documentation skills.

## Tools Used

- Spiceworks Help Desk
- Web browser
- Windows workstation
- Screenshots for documentation

## Lab Activities

This lab included three main activities:

1. Simulated ticket creation
2. Ticket closure checklist
3. Escalation practice
